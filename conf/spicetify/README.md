# Spicetify Enhancements

| Enhancement               | Description                                                                                        |
| ------------------------- | -------------------------------------------------------------------------------------------------- |
| [`Adder`](adder.js)       | A keyboard-first playlist picker for quickly adding or removing current track.                     |
| [`Settings`](settings.js) | Applies consistent playback, audio quality, crossfade, volume, zoom, and compact-view preferences. |
| [`Spotifix`](spotifix.js) | Shortcut to random/shuffled playback.                                                              |
